# CLAUDE.md

Interview-demo MVP: AI product data center for a truck-parts export company (Django 5.2 + PostgreSQL/pgvector).

## Read first
- `docs/PRD.md` — scope, user stories, acceptance criteria, priorities (P0/P1/P2).
- `docs/DESIGN.md` — architecture, data model, matching/scoring algorithms, ADRs (design decisions and trade-offs).

When adding a feature or changing architecture, update PRD (feature list, acceptance, change log) and DESIGN (affected section; append a new ADR instead of rewriting old ones).

## Commands
- DB: `docker compose up -d db` (host port 5440)
- Run: `uv run python manage.py runserver` (set `Q_SYNC=True` in `.env` or run `uv run python manage.py qcluster`)
- Reset demo data: `uv run python manage.py seed_demo`
- Tests: `uv run pytest` (needs the db container; AI is forced to mock in tests)

## Conventions
- Matching logic lives only in `apps/inquiry/matching.py`; ingest reuses it.
- Every LLM call goes through `apps/ai/client.py` (pydantic-validated, logged to AICallLog, mock fallback in `apps/ai/mock.py`). Default prompts: `apps/ai/prompts/*.txt`.
- Prices are computed in `apps/suppliers/pricing.py`, never generated by AI. AI must not write part numbers, prices or fitment.
- Quality rules: add a `@rule` function in `apps/quality/rules.py`.
- UI text in Chinese (internal users); customer-facing generated content in English.
